# Career Finder 验证记录

核验日期：2026-10-24。原始资料由 Agent 联网搜索并打开企业／机构原页，条目见 data/automation_quality.json；快照不代表日后仍有效。

## 用户案例

中控技术质量管理部 CQE，流程工业自动化；用户确认工作同时覆盖客诉、硬件和软件／交付。

默认运行不联网，生成 HTML、Markdown、JSON。报告是已核验快照与编辑建议，不冒充当前实时搜索；公司内部任职标准、个人报考资格和雇主认可情况未知。

## 覆盖

- 三条工作主线有对应知识模块和可追溯来源。
- 其他公司不继承中控产品资料；其他行业不套用工业 CQE 认证清单。
- CQE 岗位与 ASQ CQE 证书区分；未知报名资格不判定可报考。
- 在线接口缺少密钥、连接错误和响应异常明确报告；不泄漏密钥、不伪装搜索成功。
- 搜索结果去重、域名边界检查；搜索线索不自动升级为已核验证书。
- 陈旧快照告警；恶意标题 HTML 转义；报告文件生成。

## 运行限制

Brave API 按官方文档实现，用注入的固定响应验证协议和错误分支，未使用真实付费密钥做端到端调用。无需密钥的页面抓取方案不稳定（DuckDuckGo 返回挑战页），因此不将其作为默认后端，也不绕过挑战。在线搜索无法穷尽全网。

中国质量协会页面需进一步核验完整当年指南，列为待核实，不据第三方培训网站填报门槛。当前成本与考试地点等动态字段不填。

## 本地 MiniMax 配置验证

- `.env` 从项目目录读取；系统环境变量优先，不执行 shell 或变量展开。
- `.env` 与 `.env.*` 排除提交，仅 `.env.example` 允许入库；本机密钥文件设为 0600。
- 密钥只发送到允许的 MiniMax 官方 HTTPS 接口，拒绝请求重定向。
- 单元测试共 18 项通过，包含本地配置加载、错误信息不泄露密钥、模型输出脱敏及非官方端点拒绝。
- 实际连接：MiniMax-M2.5 返回已下线，切换当前官方接口及 MiniMax-M3.1-Flash 后，服务返回 status_code=0。
- Brave 在线搜索仍未使用真实付费密钥测试，MiniMax 文本调用成功不代表全网搜索已经启用。
